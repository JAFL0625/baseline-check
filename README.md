# Baseline Compatibility API

*(API de compatibilidad de línea base)*

An Express-based API that checks if modern web features meet the [Web Platform Baseline](https://web.dev/baseline/).  
It reads a `baseline-report.json` file generated by GitHub Actions and exposes endpoints to verify browser support.

*(Una API en Express que verifica si ciertas características web cumplen con la Baseline de la Web Platform. Lee un archivo `baseline-report.json` generado por GitHub Actions y expone endpoints para verificar soporte de navegadores.)*

---

## Installation

```bash
git clone https://github.com/JAFL0625/baseline-check.git
cd baseline-check
npm install

## Running Locally

node server.js

Server runs at http://localhost:3000

API Endpoints
GET /api/report

Returns the raw baseline-report.json.

Example Response

[
  {
    "feature": "CSS Grid",
    "compatibleBrowsers": ["chrome","firefox","safari","edge"],
    "baselineOK": true
  }
]

POST /api/compatibility

Check if a list of features meets the baseline.

Request Body

{
  "features": ["CSS Flexbox","CSS Grid","JavaScript BigInt","HTML Canvas"]
}

Example Response

[
  {
    "feature": "CSS Flexbox",
    "compatibleBrowsers": [],
    "baselineOK": false
  },
  {
    "feature": "CSS Grid",
    "compatibleBrowsers": ["chrome","firefox","safari","edge"],
    "baselineOK": true
  }
]
